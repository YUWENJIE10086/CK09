# 烤房全周期信息化管理平台 — 产品需求文档（PRD）

## 1. 产品概述

烤房全周期信息化管理平台是面向烟草行业的烤房管理Web端系统，基于RuoYi框架搭建，实现烤房档案管理、维修管护、预约调度、评价反馈和智能决策等全周期信息化管理。系统面向技术员、合作社、站管理员、县区局管理员、市局管理员等多级角色，实现"底数清、状态明、过程管、辅助决策"四大目标。

- 解决烤房底数不清、状态不明、维修流程线下化、预约冲突、评价缺失等痛点
- 目标用户：烟草行业各级管理人员（技术员→合作社→站→县区局→市局）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 技术员 | 管理员分配账号 | 维修提报、烤房信息更新、现场录入 |
| 合作社 | 管理员分配账号 | 管护任务分配、维修审核、预约审核、评价管理 |
| 站管理员 | 管理员分配账号 | 烤房信息查询、维修审批、预约审核、数据统计 |
| 县区局管理员 | 管理员分配账号 | 全县区烤房查询、维修审批、资金管理、BI看板 |
| 市局管理员 | 管理员分配账号 | 全市烤房管理、新建烤房、资金分配、BI大屏、数字孪生、系统配置 |

### 2.2 功能模块

1. **登录页**：账号密码登录、验证码、记住密码
2. **工作台Dashboard**：根据角色动态展示数据卡片、图表、待办事项
3. **烤房信息管理**：烤房列表（双视图切换）、烤房详情、新建烤房、信息更新
4. **维修管理**：维修提报、维修审批（多级）、线上督办验收、维修资金分配
5. **预约管理**：预约审核列表、预约日历视图、超时预警
6. **评价管理**：评价列表、评价分析统计
7. **智能分析**：健康评分与预测、烤房智能推荐配置、维修资金优化
8. **数字孪生可视化**：3D地图展示烤房分布与健康状态
9. **BI大屏分析**：多维度数据可视化大屏
10. **管护队伍管理**：四支队伍信息管理
11. **年度数据更新**：批量数据导入
12. **系统管理**：用户/角色/菜单/部门/字典/日志管理

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝 #1A3C6E（行业稳重感）+ 翠绿 #2ECC71（烟草生机感）
- **辅助色**：橙色 #F39C12（预警）+ 红色 #E74C3C（紧急）+ 灰色 #95A5A6（退出/禁用）
- **背景色**：浅灰 #F5F7FA
- **按钮风格**：Element Plus默认风格，主要操作蓝色实心、次要操作白色边框、危险操作红色
- **字体**：思源黑体 / PingFang SC，正文14px，标题18-24px
- **布局风格**：左侧菜单 + 顶部导航栏 + 内容区，经典后台管理布局
- **图标**：Element Plus Icons + Lucide Icons

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 登录页 | 登录表单 | 深色背景+毛玻璃卡片、Logo、输入框、验证码、登录按钮 |
| 工作台 | 数据卡片 | 4个统计卡片（带图标+趋势箭头）、ECharts图表、待办列表 |
| 烤房列表 | 筛选+表格 | 折叠筛选区、斑马纹表格、状态Tag标签、评分进度条 |
| 烤房列表 | 地图视图 | 高德地图、自定义Marker、信息弹窗 |
| 烤房详情 | 信息展示 | Tab页签、仪表盘、时间轴、雷达图 |
| 维修管理 | 流程展示 | Steps步骤条、审批时间轴、照片墙 |
| BI大屏 | 数据大屏 | 深色主题、大数字卡片、ECharts图表、滚动预警 |

### 4.3 响应式

- 桌面优先设计，主要适配1920x1080和1366x768
- 侧边栏可折叠
- 表格列宽自适应

### 4.4 数字孪生3D场景

- 环境：高德地图3D图层 + Three.js叠加
- 灯光：自然光环境
- 相机：俯视视角，支持缩放旋转
- 交互：点击烤房模型弹出信息卡片
- 颜色编码：优良绿色/需维护黄色/急需修复红色/退出灰色
- 动画：风险预警闪烁效果
