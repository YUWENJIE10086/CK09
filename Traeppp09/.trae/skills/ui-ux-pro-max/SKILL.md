## Chart Styling Guide

For ECharts/Chart.js:
- Use palette colors as series colors
- Match font-family to the chosen font pairing
- Apply glass/neumorphic effects to chart containers
- Use gradient fills for area/bar charts
- Style tooltips to match the overall design language
