# CK09 管理后台审计整改闭环清单 V1.1

## 3.10 SQL 注入
- 风险入口：HealthAlgoController 动态算法列名。
- 整改：健康算法、寿命算法分别建立固定白名单；apply/list/stats 在构造动态列名前统一校验。
- 复测：传入不存在算法名、SQL 特殊字符、注入表达式，应返回参数错误且不执行异常列名 SQL。

## 3.11 CORS
- 整改：删除 WebMvcConfig 中重复 CORS；SecurityConfig 改为 CORS_ALLOWED_ORIGINS 配置驱动；allowCredentials=false。
- 复测：任意未配置 Origin 不应获得 Access-Control-Allow-Origin。

## 3.12 AI Query 未授权
- 整改：删除 /barn/ai-query/** 的 permitAll；增加 ROLE_ADMIN / ROLE_AI_QUERY；AI_QUERY_API_KEY 仅通过部署配置注入。
- 复测：无 JWT、无 API Key 应 401；有效 API Key 可进入 AI Query；普通 ROLE_USER 不应进入。

## 3.13 路径穿越
- 整改：图片路径只允许图片扩展名；Path.normalize 后必须位于 upload 根目录；外部 URL 拒绝；不改变原有图片接口的公开访问属性。
- 复测：../、..\\、绝对路径、外部 URL、非图片扩展名均应拒绝。

## 3.14 IDOR / 权限提升
- 整改：updatePwd 忽略请求 userId，改用 SecurityContext 当前用户；resetPwd/changeStatus 等管理操作要求 ADMIN。
- 复测：普通用户不能修改他人状态/重置他人密码。

## 3.15 Mass Assignment
- 整改：新增/编辑使用 SysUserDTO；不直接绑定 SysUser；新增用户强制 userType=01；敏感字段不接受客户端批量覆盖。
- 复测：提交 userType/status/delFlag 等额外字段，不应改变服务端权限属性。

## 3.16 RBAC
- 整改：userType=00 映射 ROLE_ADMIN，其余映射 ROLE_USER；JWT 增加 role；管理控制器增加 ADMIN 限制。
- 复测：普通账号访问管理接口应 403；管理员可正常访问。

## 3.17 默认凭据
- 整改：数据库重建/结构脚本删除固定默认 BCrypt 哈希；新增 seed template 使用部署期占位符；登录增加 5 次失败/15 分钟临时锁定。
- 复测：仓库不得出现审计报告中的固定哈希；初始化不得继续使用统一默认密码。

## 历史归档处理

整改分支已移除根目录历史 `后台管理程序.zip`，原因是该归档可能包含整改前代码；`main` 分支未修改该历史文件。正式送审应以整改分支中的源码和重新打包后的交付物为准，避免旧归档被扫描器重复命中。

## 复测边界

静态整改已完成，但仍需在实际部署环境验证：Maven 编译、数据库初始化、登录/权限回归、CORS、AI Query、图片接口以及第三方扫描器结果。另需确认仓库中的历史二进制归档是否会被审计工具扫描；若扫描，应使用整改后的可交付包替换/隔离旧归档。
